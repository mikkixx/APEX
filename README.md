# APEX — Система управления спортивной подготовкой

Десктопное приложение для управления тренировочным процессом спортсменов. Объединяет спортсменов, тренеров и врачей в единую платформу с разграниченным доступом по ролям.

---

## Роли в системе

| Роль | Возможности |
|------|-------------|
| **Спортсмен** | Просмотр тренировочного плана, ведение дневника нагрузок, просмотр медкарты, чаты, профиль |
| **Тренер** | Управление своими спортсменами, создание и редактирование тренировочных планов, просмотр дневников и медданных, чаты, отчёты |
| **Врач** | Управление своими спортсменами, проведение медосмотров, добавление показателей и рекомендаций, просмотр тренировочных данных, чаты, отчёты |

---

## Функциональность

### Спортсмен
- **Тренировочный план** — просмотр занятий по датам, отметка статуса выполнения (выполнено / пропущено), детали занятия с рекомендациями тренера
- **Дневник нагрузок** — добавление и редактирование записей (тип занятия, длительность, шаги, сон, усталость, настроение, комментарий), фильтрация по дате и типу занятия, постраничный просмотр
- **Медкарта** — просмотр медосмотров с показателями (критичные значения подсвечиваются красным), рекомендации врача, фильтрация по дате и типу осмотра
- **Профиль** — просмотр и редактирование личных данных, смена пароля, загрузка и удаление фото
- **Чаты** — переписка с тренерами и врачами, поиск по сообщениям, фильтрация по дате

### Тренер
- **Мои спортсмены** — список закреплённых спортсменов, добавление по email, просмотр профиля каждого спортсмена
- **Профиль спортсмена** — вкладки: тренировочный план (создание, добавление занятий, удаление), дневник нагрузок (просмотр + рекомендации), медицинские показатели (только чтение)
- **Отчёты** — генерация отчётов в форматах PDF и Excel (тренировочные, медицинские, общие), выбор спортсмена и периода, сохранение в произвольную папку
- **Чаты** — переписка со спортсменами и коллегами

### Врач
- **Мои спортсмены** — аналогично тренеру
- **Профиль спортсмена** — вкладки: медицинские показатели (создание осмотров, добавление метрик с нормами, рекомендации), тренировочный план (только чтение), дневник (просмотр + рекомендации)
- **Медосмотр** — тип осмотра (текстовое поле), произвольное количество показателей (название, значение, единица измерения, норма в формате `4.0-4.6`). Значения вне нормы автоматически помечаются как критичные и подсвечиваются красным
- **Отчёты** — аналогично тренеру

## База данных

Используется **MySQL**. Схема создаётся автоматически через Peewee ORM при первом запуске `db/models.py`.

### Таблицы

| Таблица | Описание |
|---------|----------|
| `users` | Пользователи (спортсмен / тренер / врач) |
| `specialist_bindings` | Привязка специалистов к спортсменам |
| `training_plans` | Тренировочные планы |
| `sessions` | Занятия внутри плана |
| `training_diary` | Записи дневника нагрузок |
| `medical_exams` | Медицинские осмотры |
| `medical_metrics` | Показатели осмотра (с нормами и флагом критичности) |
| `recommendations` | Рекомендации специалистов |
| `messages` | Сообщения в чатах |
| `readiness_status` | Статус готовности спортсмена |

## Установка и запуск

### Требования

- Python 3.11+
- MySQL Server 8.0+
- Windows 10/11 (для `.exe` сборки)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-username/apex.git
cd apex
```

### 2. Создать виртуальное окружение

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # macOS / Linux
```

### 3. Установить зависимости

```bash
pip install PyQt6 peewee pymysql bcrypt openpyxl reportlab pyinstaller
```

### 4. Настроить базу данных

Создай базу данных в MySQL:

```sql
CREATE DATABASE apex CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Укажи параметры подключения в `db/connection.py`:

```python
db = peewee.MySQLDatabase(
    'apex',
    user='root',
    password='your_password',
    host='localhost',
    port=3306,
    charset='utf8mb4'
)
```

Создай таблицы:

```bash
python db/models.py
```

### 5. Запустить приложение

```bash
python main.py
```

## Сборка в .exe (PyInstaller)

```powershell
pyinstaller --noconfirm --onedir --windowed --name APEX `
  --add-data "fonts;fonts" `
  --add-data "img;img" `
  --hidden-import PyQt6.QtCore `
  --hidden-import PyQt6.QtWidgets `
  --hidden-import PyQt6.QtGui `
  --hidden-import peewee `
  --hidden-import pymysql `
  --hidden-import bcrypt `
  --hidden-import openpyxl `
  --hidden-import reportlab `
  main.py
```

Готовое приложение появится в папке `dist/APEX/`. Рядом с `APEX.exe` автоматически создастся папка `reports/` для сохранения отчётов.
